# Clase1
Clase1
Mi primera página web semántica y estilizada

Descripción
Este proyecto consiste en una página web de kinesiología desarrollada con HTML5 y CSS3. Incluye una estructura semántica, un menú de navegación, una imagen, una lista ordenada y un formulario de contacto.

Tecnologías utilizadas
- HTML5
- CSS3
- Variables CSS
- Selectores de clase e ID

Archivos del proyecto
- `index.html`: estructura de la página.
- `styles.css`: estilos y diseño visual.
- `kinesiologo.jpg`: imagen utilizada en la página.

Cómo abrir el proyecto
1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en un navegador web.
